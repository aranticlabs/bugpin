# Widget Changelog v1.2.1

## Heads up before upgrading

- The hosted `/widget.js` served by BugPin 1.3.1 already includes these changes. This release is for the `@arantic/bugpin-widget` npm package.

## Features

### Capturing menus, dropdowns, and hover states

- Reporters can paste an image into the **Screenshots** tab with Ctrl+V (Cmd+V on macOS). Pasted images are checked like uploads, and pasting into the title or description works as before.
- **Open Screenshot Tool** in the **Screenshots** tab opens a capture bar, like the recording bar. **Capture** takes the screenshot right away, or after a delay of 3, 5, or 10 seconds chosen from the timer menu, so reporters can reopen a menu or hover over an element first. The countdown runs inside the **Capture** button, is announced to screen readers, and is not part of the screenshot. The widget remembers the last delay in the browser.
- Delayed capture also works with the Screen Capture API: the tab share is requested when the capture bar opens. If the reporter declines, the widget captures the page itself.
- New `BugPin.capture()` method screenshots the current page and opens the dialog with the screenshot attached.
- New opt-in keyboard shortcut for `BugPin.capture()`, set with the `captureShortcut` init option or the `data-capture-shortcut` script attribute, for example `Alt+Shift+S`. The shortcut does nothing while typing in a text field.

### Annotation editor zoom and maximize

- A new button in the top-right corner of the toolbar maximizes the annotation editor to fill the browser window, and switches it back. The editor always opens at its default size, and phones stay full screen. While maximized, **Cancel** and **Done** are compact and aligned to the right.
- Zoom with Ctrl+wheel (Cmd+wheel on macOS) or a trackpad pinch around the pointer, and pan with the mouse wheel. Two-finger pinch works on touch screens and in Safari.
- Zoom out, the zoom level, and zoom in float in the bottom-right corner of the canvas. Clicking the zoom level fits the screenshot to the editor, and the screenshot refits when the editor is resized while it is fitted.
- Annotations keep their size when zooming, drawing stops at the edge of the screenshot, and exports keep the screenshot's original resolution.

## Changed

- The widget keeps the same size on every website. Before, it followed the website's root font size, so text and controls were very small on some sites.
- The annotation canvas fills the whole editor instead of a fixed minimum width.
- The annotation editor now sits above the launcher button, which no longer covers **Done**.
- The screenshot and recording bars turn light on dark websites, so they stand out from the page.
- The annotation toolbar and zoom controls show the widget's own tooltips instead of the browser's, and the color swatches are named. Widget tooltips appear after a short delay.
- The recording bar's discard button uses the same close icon as the screenshot bar.
