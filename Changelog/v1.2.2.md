# Changelog v1.2.2

### Heads up before upgrading

- A database migration adds a `widget_version_observations` table. It runs automatically on first launch; no manual step is required.

### Features

#### Widget package compatibility warnings

- Administrators now see an independently dismissible warning when recently active npm widget deployments use a package version older than the server's supported minimum.
- The warning identifies affected projects, observed versions, and deployment counts, and links directly to the package versions page.
- Programmatic `BugPin.init()` integrations report their package version during the existing configuration request. Hosted `/widget.js` integrations remain unchanged.
- Compatibility checks are local and continue to work when remote BugPin update checks are disabled.

#### Reporter prefill

- Widget integrations can prefill the editable reporter name and email through `BugPin.init()` or script-tag data attributes.
- Reporter-prefilled drafts are scoped by reporter email to avoid restoring another reporter's saved form data.
- The Admin Console's Test Widget page now lets administrators edit the test reporter and switch between reporter and logged-out modes.
